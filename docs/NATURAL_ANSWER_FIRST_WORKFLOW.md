# Natural-Answer-First Workflow

## The client question comes first

The workflow begins with a buyer question in the language a real buyer would use. The operator records the question, capture surface, model configuration, session mode, timestamp, and operator. A clean, context-neutral session is required for market-facing captures.

The captured answer is the record of what that surface showed at that moment. It is preserved before any interpretation. The platform does not rewrite the buyer question for the client view or present a source-disclosure prompt as a buyer question.

## The answer creates the candidate set

Visible URLs in the preserved answer become **source candidates**. Each candidate record includes the exact URL, answer location, named entity, publisher, source type, and a publisher-relationship review. A self-published agency list, vendor comparison, review platform, forum discussion, and editorial publication are different source types and must remain visibly distinct.

Only an approved candidate can enter the secure collection workflow. Approved collection creates the evidence ledger, retained snapshot, verifier result, and quote record. The answer remains an observation. The collected page becomes evidence. The system keeps those roles separate.

## What the client receives

The client view follows a simple sequence:

1. **Buyer question.** The question used in the captured answer.
2. **What appeared.** The companies, products, or publishers named in that answer.
3. **Where the answer came from.** The visible source URLs and their publisher context.
4. **What the pages show.** Verified passages from approved collected sources.
5. **What to strengthen next.** A human-reviewed plan for clearer proof, stronger public evidence, and legitimate exposure.

## Evidence boundaries

The answer can establish that a model named an entity or visibly linked a page. It cannot establish the model's complete internal source set or ranking formula. A collected page can establish its visible content and publisher context. It cannot prove that the page caused the answer.

The report uses the following labels:

| Label | Meaning |
| --- | --- |
| **Observed in answer** | Present in the captured model response. |
| **Verified source evidence** | Present in an approved collected page with retained snapshot and verifier record. |
| **Publisher-owned source** | The publisher promotes itself or has a direct commercial interest in the entity discussed. |
| **Evidence opportunity** | A human-reviewed area where the client can build clearer proof or earn credible coverage. |

## Operator stop conditions

Stop the workflow when the answer contains account-specific context, the capture session is not clean, visible sources cannot be preserved, candidate URLs cannot be approved safely, or collected evidence does not support a useful next action. The report should state that the evidence did not support a decision and close the run.
