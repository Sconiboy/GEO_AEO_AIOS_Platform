## Finding

### P0 — Execution provenance remains forgeable despite context integrity checks

`CollectionExecutionRecord.verify_integrity()` recomputes a public SHA-256 over fields supplied with the record. The comparative gate verifies that digest, finds an execution by evidence ID in the gap record, compares its fields to current artifacts, and requires an authorized candidate. [1] [2] These are valuable integrity checks, and the field-mutation matrix shows that they reject stale or cross-context executions.

They do not establish **origin authenticity**. The independent harness created `exec-client-self-consistent-forgery`, retained all required current bindings, recomputed the record’s canonical digest, retained the matching authorized candidate, recomputed the gap-record digest, updated the human quote to the new execution ID, and recomputed the human-decision digest. The comparator returned `SUPPORTED`. This is a foreign execution because it was not generated or attested by the candidate-collection workflow; the final gate has no independent state against which to distinguish it.

The integrity of the gap record does not cure the problem because its digest is also a public recomputation over the supplied list of candidates and executions. [3] The human decision is likewise content-addressed but not authenticated by an external signer or immutable decision registry. [5]

## Next Action

The remediation should remain narrow and testable. Add a durable, collector-controlled execution registry or append-only event store and bind each execution to a verifier- or collector-issued authenticity proof that the comparative gate resolves independently. At promotion, require that the selected `execution_id` exists in that registry, that its stored canonical bytes and/or signature verify, and that its complete stored context exactly matches the current raw evidence ledger, observation, profile, query map, manifest, snapshot, verifier run, authorized candidate, and evidence record.

Add an adversarial regression that constructs the same new-ID, fully rehashed execution used in this review and proves that comparative promotion fails unless the execution was issued by the authorized collection workflow and independently retrievable from the registry. Keep the existing six quote-binding, execution-field, raw-artifact, and retained-snapshot tests.
