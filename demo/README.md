# Source-First Client Page Demo

Open `source-first-client-page.html` in a browser to view the first client-facing evidence-map page.

The page leads with a buyer question, shows an example AI-answer result, maps the visible source evidence, identifies the next evidence question, and gives the team a 90-day proof-and-exposure plan. It deliberately communicates the service outcome rather than the internal query-design process.

The sample uses the governed public B2B SaaS SEO pre-pilot artifacts. Its source cards and evidence IDs trace back to the frozen capture and source ledger in `data/prepilot/`.
